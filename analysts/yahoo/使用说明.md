# Yahoo Finance 数据获取工具 - 简化版

## 新增功能

在原有`yahoo.py`文件基础上添加了两个导出功能：

### 1. CSV导出 - K线图历史数据
```python
# 导出K线数据到CSV
tool = YahooFinanceTool(output_dir="stock_data")
csv_path = tool.export_kline_to_csv("AAPL", period="1mo", interval="1d")
```

**CSV文件包含：**
- 日期、开盘价、最高价、最低价、收盘价、成交量
- 移动平均线：5日、10日、20日、50日均线
- 技术指标：RSI、MACD、布林带、随机指标K/D
- 成交量指标：10日、20日平均成交量
- 波动性指标：平均真实波幅(ATR)

### 2. JSON导出 - LLM分析数据
```python
# 导出分析数据到JSON
json_path = tool.export_analysis_to_json("AAPL", period="1mo", interval="1d")
```

**JSON文件包含：**
- **股票基本信息**：价格、市值、PE、PB、Beta等
- **技术指标**：
  - 移动平均线：MA20/50及价格相对位置
  - 震荡指标：RSI、随机指标K/D、MACD
  - 布林带：上轨、下轨及价格相对位置
  - 成交量指标：20日均量及相对比例
  - 波动性指标：ATR及相对百分比
- **价格分析**：
  - 价格区间：1个月高低点、平均价格、波动率
  - 趋势分析：20日、30日趋势百分比
  - 关键价格水平：支撑位和阻力位数组
- **数据摘要**：历史数据点数、时间范围等

## 更新说明

### 新增功能
- **移除market_sentiment部分**：简化JSON结构，专注于技术分析数据
- **自适应技术指标**：
  - **智能MA系统**：根据数据周期和间隔自动调整移动平均线窗口
  - **自适应RSI**：根据时间框架调整RSI计算周期
  - **智能MACD**：根据数据频率调整MACD参数
  - **动态布林带**：根据数据间隔调整布林带窗口
  - **自适应成交量指标**：根据时间框架调整成交量均线
  - **智能随机指标**：根据数据周期调整随机指标参数
  - **动态ATR**：根据时间间隔调整ATR计算窗口
- **关键价格水平**：自动识别支撑位和阻力位
- **趋势分析**：20日和30日趋势百分比
- **保持1个月历史数据**：确保数据获取速度和稳定性

### 修复说明
- 修复了财务数据获取时的`NoneType`错误
- 移除了已弃用的`earnings`API调用
- 移除了不可用的搜索功能，简化代码结构
- 增强了错误处理，确保即使某些数据获取失败也能正常导出
- JSON导出现在只使用可靠的数据源，避免API限制问题

### 功能限制
- **数据可用性**：某些数据可能因市场关闭或数据源问题而不可用
- **股票代码输入**：需要输入准确的股票代码（如AAPL），不支持公司名称搜索

## 数据点调节

### CSV和JSON导出都支持自定义数据点数量：

```python
# 获取更多数据点（3个月，约60个数据点）
csv_path = tool.export_kline_to_csv("AAPL", period="3mo", interval="1d")
json_path = tool.export_analysis_to_json("AAPL", period="3mo", interval="1d")

# 获取长期数据（1年，约250个数据点）
csv_path = tool.export_kline_to_csv("AAPL", period="1y", interval="1d")
json_path = tool.export_analysis_to_json("AAPL", period="1y", interval="1d")

# 获取高频数据（5天1小时数据，约40个数据点）
csv_path = tool.export_kline_to_csv("AAPL", period="5d", interval="1h")
json_path = tool.export_analysis_to_json("AAPL", period="5d", interval="1h")
```

### 可用的时间周期和间隔：
- **period**: 1d, 5d, 1mo, 3mo, 6mo, 1y, 2y, 5y, 10y, ytd, max
- **interval**: 1m, 5m, 15m, 30m, 1h, 1d, 5d, 1wk, 1mo, 3mo

## 自适应技术指标说明

### 智能移动平均线系统
系统会根据您选择的数据间隔自动调整MA窗口：

| 数据间隔 | MA窗口设置 | 说明 |
|---------|-----------|------|
| 1m, 5m, 15m, 30m | MA_5, MA_10, MA_20, MA_50 | 分钟级数据，短期MA |
| 1h, 60m | MA_5, MA_10, MA_20, MA_50 | 小时级数据，中短期MA |
| 1d | MA_5, MA_10, MA_20, MA_50 | 日级数据，标准MA |
| 5d, 1wk | MA_3, MA_5, MA_10, MA_20 | 周级数据，长期MA |
| 1mo, 3mo | MA_2, MA_3, MA_5, MA_10 | 月级数据，超长期MA |

### 自适应指标参数
- **RSI窗口**：分钟/小时/日数据=14，周数据=7，月数据=5
- **MACD参数**：分钟/小时/日数据=(12,26,9)，周数据=(6,13,5)，月数据=(3,6,2)
- **布林带窗口**：分钟/小时/日数据=20，周数据=10，月数据=5
- **ATR窗口**：分钟/小时/日数据=14，周数据=7，月数据=5

### 实际应用示例
```python
# 5分钟数据 - 适合日内交易
csv_path = tool.export_kline_to_csv("AAPL", period="1d", interval="5m")
# 生成：5个5分钟均线、10个5分钟均线、20个5分钟均线、50个5分钟均线

# 周数据 - 适合长期投资
csv_path = tool.export_kline_to_csv("AAPL", period="2y", interval="1wk")
# 生成：3周均线、5周均线、10周均线、20周均线

# 月数据 - 适合超长期分析
csv_path = tool.export_kline_to_csv("AAPL", period="5y", interval="1mo")
# 生成：2月均线、3月均线、5月均线、10月均线
```

## 使用方法

```python
from yahoo import YahooFinanceTool

# 创建工具实例
tool = YahooFinanceTool(output_dir="output")

# 导出CSV
csv_file = tool.export_kline_to_csv("AAPL", period="3mo", interval="1d")

# 导出JSON
json_file = tool.export_analysis_to_json("AAPL", period="3mo", interval="1d")

print(f"CSV文件: {csv_file}")
print(f"JSON文件: {json_file}")
```

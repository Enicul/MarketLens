## X_search 使用说明

本工具使用 Playwright 抓取 X/Twitter 上与股票相关的帖子，支持关键词增强、Top/Latest 切换、在线质量过滤与（可选）评论抓取，并支持登录态持久化以避免重复登录。

### 目录结构
- `search.py`：核心爬虫逻辑（异步 Playwright）
- `run_scraper.py`：命令行入口示例
- `config.py`：配置项（时间窗、关键词、过滤、Tab、会话持久化等）
- `auth_state.json/.auth_state.json`：登录态存储文件（自动生成）

### 环境准备（Windows PowerShell）
```powershell
cd T:\AIS\PROJ1
python -m pip install -r maker_lens\data_agent\X_search\requirements.txt
playwright install chromium
```

首次建议可视化运行（会弹出浏览器），完成登录后会自动保存登录态：
```powershell
python maker_lens\data_agent\X_search\run_scraper.py AAPL 30
```

### 快速开始
- 抓取单个标的（默认从今天起往前5天，语言不限，Latest/Top 由配置决定）：
```powershell
python maker_lens\data_agent\X_search\run_scraper.py NVDA 50
```
- 运行 `search.py` 中的示例主函数（多标的示例）：
```powershell
python maker_lens\data_agent\X_search\search.py
```

输出文件：会在当前目录生成 `TICKER_tweets_YYYYMMDD_HHMMSS.json/csv`。

### 关键配置（config.py）
- 浏览器与会话
  - `HEADLESS`: 是否无头（首次建议 False 手动登录）
  - `STORAGE_STATE_PATH`: 登录态存储文件（默认已设置，登录后自动生成/更新）
- 搜索行为
  - `SEARCH_TAB`: `'latest'` 或 `'top'`（Top 首屏常有“相关用户”，已内置滚动重试）
  - 时间窗：`SINCE/UNTIL`（默认：今天起往前5天至今天，UTC）。设为 `None` 可关闭限制
  - 语言：`LANG`（如 `'en'`/`'zh'`，或 `None` 不限制）
  - 关键词增强：`FINANCE_KEYWORDS`（简洁金融词列表；可设为空以放量）
  - 个股关键词：`SEARCH_KEYWORDS`（每个标的的 cashtag/别名）
- 质量过滤（在线过滤与抓取后过滤共用阈值）
  - `MIN_LIKES / MIN_RETWEETS / MIN_REPLIES / MIN_TEXT_LEN`
  - 建议：放量验证时先设为 0，再逐步提高
- 滚动/数量
  - `MAX_SCROLL_ATTEMPTS`: 滚动次数（网络慢时可增大，如 50）
  - `MAX_TWEETS_PER_STOCK`: 期望抓取条数（`run_scraper.py` 也可传入第二个参数）
- 评论抓取（可选）
  - `FETCH_REPLIES`: 是否抓取评论
  - `MAX_REPLIES_PER_TWEET`: 每条主贴抓取评论上限
  - `REPLIES_MIN_TEXT_LEN`: 评论最小文本长度

### 数据字段
每条主贴包含：`username, user_id, content, timestamp, likes, retweets, replies, is_retweet, is_reply`

注：已按你的需求移除 `urls` 与抓取元数据；如需恢复以支持新闻域过滤或精确详情页定位，可再开启。

### 常见问题
1) 一直要求登录 / 每次都要登录
   - 首次用可视化模式登录（`HEADLESS=False`），登录后会自动写入 `STORAGE_STATE_PATH`，下次自动加载。
2) 搜索成功但不下滑、不出结果
   - 先改成 `SEARCH_TAB='latest'` 验证；Top 页首屏常为相关用户卡片，已内置“未识别到则滚动再试”，但若仍少，请放宽时间窗与阈值。
   - 增大 `MAX_SCROLL_ATTEMPTS`，将 `DELAY_RANGE` 稍微调大（如 `(1.2, 2.0)`）。
3) 结果数量很少
   - 放量策略：`FINANCE_KEYWORDS=[]`、`SINCE/UNTIL=None`、`MIN_*` 全设为 0、`SEARCH_TAB='latest'`，确认有量后再逐步加回限制。
4) Windows 退出时提示 asyncio/pipe 警告
   - 属于已知提示，代码已按顺序关闭 `context/browser` 并停止 Playwright；不影响结果。

### 建议用法组合
- 高质量主贴：`SEARCH_TAB='top'` + 提高 `MIN_LIKES/MIN_RETWEETS` + 适度滚动次数
- 广覆盖：`SEARCH_TAB='latest'` + 放宽时间窗 + 较低阈值
- 主贴+评论：在广覆盖或高质量基础上，开启 `FETCH_REPLIES` 抓取 5–10 条精选评论
